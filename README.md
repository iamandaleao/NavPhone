# Projeto Redes Sociais

Projeto desenvolvido durante o Módulo 04 do curso de HTML5 e CSS3 do Curso em Vídeo, simulando a integração de redes sociais e criando uma tela de login responsiva.

## O que foi praticado
- Uso de iframes para incorporar conteúdos externos (vídeos, mapas, sites)
- Criação de formulários com campos variados (texto, e-mail, senha, número, upload)
- Diferença entre métodos GET e POST
- Construção de layout responsivo com media queries
- Implementação de menu “hambúrguer” para dispositivos móveis

## O que aprendi
- Incorporar conteúdos externos de forma segura e eficiente
- Desenvolver formulários completos para interação usuário-servidor
- Aplicar design responsivo adaptado a diferentes tamanhos de tela
- Criar interfaces mais profissionais e preparadas para dispositivos móveis

## Tecnologias
- HTML5
- CSS3
